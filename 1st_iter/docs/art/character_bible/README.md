# Character reference index

These are byte-for-byte copies of user-supplied reference images from the
repository's `assets/` directory. No license or authorship was supplied;
no third-party license is inferred here.

| Original file | Canonical file here | Purpose |
| --- | --- | --- |
| `assets/player_master_reference.png` | `player_master_reference.png` | Identity, costume details, materials, labeled palette |
| `assets/player_turnaround.png` | `player_turnaround.png` | Front, back, side, and three-quarter proportions |
| `assets/player_keyposes.png` | `player_keyposes.png` | Labeled animation key poses |
| `assets/player_palette.png` | `player_character_bible.png` | Full character bible, including palette, silhouettes, FX, and example export specs |
| `assets/player_poses.png` | `player_poses.png` | Additional movement poses |

`player_palette.md` transcribes the readable hex labels from the master
reference. The original filename `player_palette.png` describes only one part
of the comprehensive bible sheet, so its copy uses the name requested by the
iteration brief.

The master reference takes precedence for identity and palette. The full bible
contains optional ideas and illustrative technical values, not completed sprite
animations. Do not crop these multi-pose sheets and treat them as production
animation frames.
