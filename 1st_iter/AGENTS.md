# Art-production instructions

Read `docs/art/ART_DIRECTION.md` before creating or modifying any visual asset.
Paths in this document are relative to `1st_iter/`.

- Use `docs/art/character_bible/` as the canonical player reference. Preserve the character design.
- Keep reference sheets in `docs/art/`; place approved game-ready exports in `assets/` and editable production files in the corresponding `source/` folder.
- Never use the reference sheets directly as gameplay sprites.
- Build environment assets as separate layers according to `docs/art/environment_bible/README.md`.
- Keep work for this iteration inside `1st_iter/` and record significant changes in its `AGENT_HANDOFF.md`.
